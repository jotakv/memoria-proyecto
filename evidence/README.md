# Evidencia del expediente

Este directorio mantiene el índice probatorio de Allsetic AI Automation Studio. No debe contener datos personales sensibles en claro si el repositorio puede compartirse.

## Reglas

- Registrar existencia, fecha, titular, finalidad y ubicación segura del documento.
- Utilizar copias redactadas para revisiones públicas.
- No considerar un dato confirmado solo porque aparezca en la narrativa.
- Vincular cada inversión con presupuesto, factura o contrato y prueba bancaria.
- Conservar justificantes de registro y versiones presentadas sin sobrescribirlas.
- No versionar secretos, DNI, cuenta bancaria, domicilio privado o documentación laboral completa.

Los tres PDF de `documentos_sepe/` son copias oficiales preexistentes y se conservan sin modificación. No son evidencia personal del promotor.
