# Evidence — Expediente probatorio

Esta carpeta no sustituye al archivo original de los documentos administrativos, bancarios, fiscales o inmobiliarios. Su función es mantener un **inventario trazable** de la evidencia que soporta la memoria, el modelo financiero y la justificación del pago único.

## Reglas

1. No alterar documentos oficiales.
2. Mantener nombre original, fecha, emisor y estado.
3. Registrar si el documento está disponible, pendiente o desactualizado.
4. Vincular cada documento con las afirmaciones que soporta.
5. Conservar justificantes de pago bancario junto con facturas/escrituras/contratos.
6. Evitar datos personales innecesarios en ramas públicas si el repositorio permanece público.
