# 02 · Plan de empresa vigente

Allsetic AI Automation Studio prestará consultoría tecnológica, automatización, integración y software con operativa híbrida, inicialmente como profesional autónomo sin empleados confirmados. No existen clientes, contratos, ventas o facturación acreditados en este expediente.

El plan económico oficial se limita a fuentes, inversión y una prueba simplificada de liquidez. No hay información suficiente para una previsión anual comercial ni una tesorería mensual completa sin hipótesis adicionales. El modelo de 63.000 € de ventas está clasificado como histórico y no es la previsión vigente.

La sede se justifica por puesto técnico permanente, separación vivienda/actividad, custodia, archivo, administración, continuidad, reuniones, demostraciones y formación. Es un activo instrumental sin finalidad residencial, arrendadora, especulativa o de reventa. No se comprará si el coste integral y las necesidades operativas no preservan circulante suficiente.
