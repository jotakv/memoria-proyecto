- Scripts de build, desarrollo, lint, typecheck, pruebas y validación.
- Registros Allsetic de estado, hipótesis, decisiones, fuentes y preguntas abiertas.

### Modificado

- Misión del repositorio, README, estructura documental y prompts operativos.
- Posicionamiento, contenido, navegación, diseño, metadatos y modelo de información.
- Referencias oficiales revalidadas el 27 de agosto de 2026.

- Duplicación por capítulos de la memoria; la fuente editorial pasa a ser única.

### Conservado

- Historial Git completo.
- Repositorio y remoto `origin` sin renombrar.
- Tres PDF oficiales del SEPE ya versionados, sin modificación y fuera del diff binario.

### Control

- No se añadieron clientes, contratos, subvenciones, certificaciones, ingresos, métricas ni presupuestos ficticios.
- `npm run check` superó lint, typecheck, 7 pruebas y build.
- Las rutas principales respondieron correctamente y los enlaces internos fueron validados.
- La inspección visual quedó pendiente porque el navegador integrado no estaba disponible en la sesión.

## 2026-08-27 · Plan de empresa integral

### Añadido

- Seis documentos textuales en `plan-empresa/`: plan autosuficiente, resumen para jurado, modelo financiero a 36 meses, registro central de hipótesis/pendientes/fuentes, matriz de cobertura y guía de mantenimiento.
- Escenarios conservador, base y crecimiento; inversión, financiación, resultados, tesorería, IVA, equilibrio, ratios y sensibilidad con fórmulas revisables.
- Análisis Canvas, PESTEL, Porter, competencia, DAFO/CAME, marketing, operaciones, gobierno de IA, riesgos y roadmap.

### Modificado

- Registros de hipótesis, preguntas, decisiones y estado; enlace desde el README raíz.

### Control

- Las plantillas DOC/XLSM y referencias complementarias se analizaron solo como estructura y permanecen intactas.
- No se incorporaron personas, empresas, importes, empleados, ubicaciones ni fiscalidad de los ejemplos.
- Todos los importes del plan son `[HIPÓTESIS]`; no se afirman ventas, ayudas, deuda ni admisibilidad SEPE.
- El cambio contiene exclusivamente texto UTF-8; no se crearon ni modificaron binarios.

### Corrección de coherencia canónica

- Reconciliada la memoria canónica con la modalidad principalmente remota y sin local comercial inicial.
- El validador excluye `referencias/` del control de términos incompatibles porque contienen ejemplos históricos obligatorios e intactos; el contenido activo continúa validándose.
