# DUE DILIGENCE DEL LOCAL

Última actualización: 2026-08-19

## Registral y jurídica

- [ ] Nota simple actualizada.
- [ ] Titularidad y cargas.
- [ ] Descripción registral vs realidad física.
- [ ] Estatutos de comunidad.
- [ ] Actas relevantes.
- [ ] Certificado de deudas de comunidad.
- [ ] Derramas aprobadas o previsibles.

## Urbanística y actividad

- [ ] Uso urbanístico admisible.
- [ ] Compatibilidad del catálogo de actividades MVP.
- [ ] Licencia/DRU/ECU aplicable.
- [ ] Aforo.
- [ ] Accesibilidad.
- [ ] Evacuación e incendios.
- [ ] Ventilación/climatización.
- [ ] Aislamiento acústico.
- [ ] Limitaciones por música/eventos.
- [ ] Rótulos/publicidad exterior.

## Técnica

- [ ] Superficie útil medida.
- [ ] Altura libre.
- [ ] Estado estructura y acabados.
- [ ] Electricidad/potencia.
- [ ] Fontanería/saneamiento.
- [ ] Climatización.
- [ ] Humedades.
- [ ] Telecomunicaciones.
- [ ] Presupuesto de adecuación.

## Edificio

- [ ] ITE/IEE.
- [ ] Obras pendientes.
- [ ] Comunidad/IBI.
- [ ] Seguro del edificio.

## Financiera

- [ ] Tasación.
- [ ] Valor de referencia fiscal cuando proceda.
- [ ] LTV/LTC posible.
- [ ] Cuota de deuda.
- [ ] Gastos de financiación.
- [ ] Caja residual post-cierre.

## Condición de compra

No considerar el local `APROBADO` hasta cerrar simultáneamente viabilidad técnica, legal y financiera.
