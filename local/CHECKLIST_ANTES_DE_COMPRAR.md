# CHECKLIST ANTES DE COMPRAR EL LOCAL

Última actualización: 2026-08-19

- [ ] Prestación contributiva reconocida y estrategia de capitalización validada.
- [ ] Forma jurídica decidida.
- [ ] Local identificado y visitado técnicamente.
- [ ] Nota simple revisada.
- [ ] Catastro revisado.
- [ ] Comunidad, derramas, ITE/IEE revisados.
- [ ] Compatibilidad urbanística/actividad confirmada por técnico competente.
- [ ] Aforo y distribución compatibles con el modelo económico.
- [ ] Presupuesto de obra y acondicionamiento cerrado o con contingencia razonable.
- [ ] Coste total de adquisición calculado, no sólo precio de compra.
- [ ] Tasación disponible o previsible.
- [ ] Preestudio de banco/Avalmadrid recibido.
- [ ] Fuentes = usos en el modelo financiero.
- [ ] Fondo de maniobra protegido tras el cierre.
- [ ] Escenario conservador soporta razonablemente el servicio de deuda.
- [ ] Arras, si existen, condicionadas a viabilidad técnica/jurídica y financiación cuando proceda.
- [ ] Cronología de pagos compatible con reglas de justificación del SEPE.
- [ ] Todos los pagos previstos son trazables bancariamente.
- [ ] No existe dependencia de ingresos SOMA OS para pagar la deuda base.
