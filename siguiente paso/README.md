# Siguiente paso — paquete de desbloqueo del promotor

## Resultado de esta iteración

Los huecos que podían cerrarse con reglas oficiales, estructura documental o cálculo reproducible ya tienen soporte. El expediente no necesita más narrativa general; necesita datos y documentos que sólo puede aportar o decidir el promotor y terceros.

## Siguiente paso recomendado

Construir y validar un **paquete mínimo de desbloqueo** con cinco bloques:

1. prestación y cierre del procedimiento laboral;
2. decisión de forma jurídica;
3. local candidato y documentación técnica/registral;
4. MVP operativo: actividades, horarios, aforo, responsables y precios;
5. fuentes y usos: fondos propios, presupuestos y financiación indicativa.

Hasta que exista ese paquete no deben fijarse impuestos, licencias, CAPEX, OPEX, demanda, salarios, cuota, DSCR o break-even.

## Criterio de terminado

El paso termina cuando cada documento está inventariado con emisor, fecha, alcance y privacidad; cada decisión está registrada; y el modelo puede calcular un año 1 mensual sin sustituir ausencias por ceros silenciosos.

El prompt operativo está en `PROMPT_IMPLEMENTACION.md`.
