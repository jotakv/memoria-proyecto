# REVISAR FINANZAS

Actúa como CFO, analista financiero y analista de riesgos.

## Revisa

- CAPEX;
- OPEX;
- ingresos;
- cash-flow;
- servicio de deuda;
- DSCR;
- break-even;
- fondo de maniobra;
- sensibilidad;
- coherencia de fuentes y usos;
- diferencias entre escenarios.

## Reglas

- No inventar importes.
- Cada cifra no confirmada debe apuntar a una hipótesis.
- El escenario bancario base debe mantener `SOMA OS = 0 €`.
- Año 1 mensual; años 2–3 anual.
- Separar costes fijos y variables.
- Incluir tests de -20 % ventas, +15 % CAPEX y retraso de apertura.

## Salida

- errores matemáticos/coherencia;
- supuestos frágiles;
- ratios que faltan;
- necesidad de caja máxima;
- capacidad de deuda;
- acciones correctivas;
- archivos actualizados.
