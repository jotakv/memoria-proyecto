# Prompts de iteración

Esta carpeta contiene prompts reutilizables para mantener el expediente vivo, auditable y coherente.

## Orden recomendado

1. `00_MASTER_AGENT.md`
2. `01_AUDITAR_MEMORIA.md`
3. `02_COMPLETAR_HUECOS.md`
4. `03_REVISAR_SEPE.md`
5. `04_REVISAR_FINANZAS.md`
6. `05_REVISAR_LOCAL.md`
7. `06_REVISAR_BANCO.md`
8. `07_REVISAR_TECNOLOGIA.md`
9. `08_REVISAR_LANZADERA.md`
10. `09_ACTUALIZAR_FUENTES.md`
11. `10_GENERAR_SIGUIENTE_ITERACION.md`
12. `99_RELEASE_FINAL.md`
13. Tras `02_COMPLETAR_HUECOS.md`, usar `../siguiente paso/PROMPT_IMPLEMENTACION.md` cuando la mayoría de bloqueadores dependan del promotor.

## Reglas transversales

- Leer todo el repositorio antes de modificarlo.
- No inventar hechos, cifras, licencias, financiación o demanda.
- Etiquetar `[CONFIRMADO]`, `[ESTIMADO]`, `[BENCHMARK]`, `[HIPÓTESIS]`, `[PENDIENTE]`.
- Mantener sincronizados `STATUS`, `OPEN_QUESTIONS`, `ASSUMPTIONS`, `DECISION_LOG` y `CHANGELOG`.
- Priorizar fuentes oficiales para hechos legales, administrativos, fiscales y financieros variables.
- No usar SOMA OS para pagar la deuda en escenario bancario base.
